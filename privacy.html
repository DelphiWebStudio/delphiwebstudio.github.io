Website privacy

this website does.

This notice covers the product website you are viewing. The Windows application has separate local-storage and optional-service behavior, described in its illustrated guides.

Last updated November 20, 2026.

Browsing and downloads

The pages, images, installers and guides are ordinary website files hosted by GitHub Pages. We have not added an analytics or advertising tracker, account registration or a contact form to this website. Download links request files from this website over HTTPS.

GitHub logs visitors' IP addresses for security purposes, whether or not they are signed in. Its handling of hosting and connection data is described in the GitHub Privacy Statement.

This website publishes the product pages, example screenshots, installers and guides. It does not receive your desktop projects, drafts, saved credentials or AI requests.

The online translation service

The floating language selector uses GTranslate, an online website translation service. Loading this widget contacts its provider, and translating a page can send page text through online translation services.

The selector can detect the browser's language and use the translation service's stored language preference. That preference is separate from any editable project in the Windows application. Browser site-data controls can be used to review or remove stored website preferences.

Translation needs JavaScript and an internet connection. The text is machine-translated, and the original English version remains available through the selector. Product names and other protected labels are marked to retain their original wording.

For the provider's handling of the online service, read GTranslate's privacy policy and service terms.

Links to other websites

Some links lead to Microsoft, Google, GitHub or another third-party provider for software requirements, service information or source code. Following one of those links opens the provider's website, where its own policies apply.

The product installers and illustrated guides offered here download directly from this website.

The Windows application is separate

Delphi Web Studio Pro keeps local drafts and settings in its Windows WebView profile, and separately saved project files stay where you choose to save them. Optional online services and external resources configured in a project have their own network behavior.

Google Gemini assistance uses a key you configure in the application. This website has no field for that key and does not receive it. Adding visitor translation to an exported website is also a separate project choice.

Read the User Guide and Engineering Guide for the application's project storage, saved credentials, optional services and recovery procedures.
