Current release · November 20, 2026

1.0 build 4 — Bullets keep their spacing.

Applying bullets now adds markers at the existing logical line starts. Paragraph and heading boundaries, blank lines, spacing, indentation, fonts, colors and links stay intact instead of the selection being extracted and rebuilt.

  • Partial selections affect the intended lines.
  • Existing bullet and list markers are left alone.
  • One Undo removes the new bullets while keeping pending wording.
  • Source-pasted heading lines retain their separate boundaries and tags.
  • Guides and both Windows installer editions are updated.

If an earlier operation already saved joined lines, use Undo, an intact earlier copy or manual editing to recover the missing breaks before applying bullets again. The update preserves existing project content rather than guessing its layout.

How was build 4 checked?

The original spacing problem was reproduced before the fix. Checks in both desktop editions covered bullet formatting, text placement, dragging, Undo/Redo and saved-project behavior. The regression suite and installer payload checks also passed, and all seven illustrated guide pairs were reviewed.

These checks used isolated example projects. They do not replace reviewing your own content and keeping a saved project before an update.

Windows file and product version: 1.0.0.4.

November 20, 2026

1.0 build 3 — Place text where you choose.

The left-panel and canvas-menu Add text commands now share one click-to-place process. Invalid destinations leave placement active rather than silently placing content at a block's top-left corner or after the footer.

A visible Move control makes text-box movement available while typing, saving pending wording before the drag. Ordinary text and paste commands appear immediately in the context menu, with formatting controls in their existing settings windows.

The update also checked movement between sections, invalid-drop recovery, Undo/Redo and the preservation of existing projects and drafts.

Windows file and product version: 1.0.0.3.

November 19, 2026

1.0 build 2 — Review locally before you share.

A permanent local test-folder workflow makes it easier to refresh exported website files and open the result in a browser. A verified pre-refresh ZIP protects affected files, while unrelated files remain separate.

Expanded Check site tools review supported text/background contrast and external-link responses. Page settings bring page names, addresses, exported-filename previews and supported internal-link updates together with Undo.

Optional TAtlas website translation adds a floating GTranslate language selector to exported pages. It translates the visitor website and leaves the editor interface and original project wording unchanged.

Windows file and product version: 1.0.0.2.
