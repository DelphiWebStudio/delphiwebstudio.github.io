About the application

A Windows editor.
An open foundation.

Delphi Web Studio Pro brings visual page design, portable projects and website export into a free, open-source desktop application.

Built around everyday work

Keep your project.
Keep your choices.

A website needs more than its first design. Photographs arrive, schedules change and new pages find their place. This editor brings those regular updates into a visual workspace you can continue to use.

The saved project is the editable source, with pages and media you can keep together. The website export is a separate set of visitor files you can test locally and place on compatible hosting.

Ordinary local editing does not require a cloud account or developer tools. Optional services, including Google Gemini assistance and SFTP uploads, have their own connection requirements.

Made for Windows

Separate 32-bit and 64-bit editions support Windows 10 and Windows 11. The visual workspace uses Microsoft Edge WebView2 Runtime, which Setup checks before installation.

The illustrated User Guide explains everyday editing, while the Engineering Guide describes the Delphi desktop host, visual editor and project model.

Acknowledge the foundation

Built on OpenPage.

Delphi Web Studio Pro is a fork of OpenPage, the free, open-source website builder created by Federico De Ponte and published on GitHub.

OpenPage uses JSON—a structured text format—as the central model for a site, combining visual drag-and-drop editing with AI-assisted website generation. Its original work, history, license and attribution remain part of this project.

The Windows edition adds extensive tools for desktop editing, local project management, media organization, reviewed AI assistance and website maintenance.

Free and open source

The application source is distributed under the MIT license, with the original OpenPage copyright and attribution preserved. Included third-party components retain their own license notices.

For the curious and the community

Look inside, learn and contribute.

The source repository provides the application code and its development history. It is available separately from the Windows downloads, which this website supplies directly.

If you're exploring how the editor works, start with the Engineering Guide. If you're reporting a problem, include the build number, Windows edition and the steps that led to it, using a small example that leaves out private project content and credentials.
