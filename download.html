What you need

A Windows PC.
Your ideas.

Ordinary editing and website export run on your computer. You do not need a cloud account, a subscription or developer tools to use the local editor.

  • Windows 10 or Windows 11.
  • Microsoft Edge WebView2 Runtime, the browser engine used inside the editor. Setup checks whether it is available.
  • A compatible hosting service when you decide to put the exported website online.

Optional connections

Google Gemini assistance uses your own Google AI project and saved API key, a credential that connects the editor to that project. Keep it on Free tier with billing disabled. Internet access and Google's availability and quotas apply.

SFTP uploads use Windows OpenSSH Client and the account, key and host details supplied by your hosting provider. You can edit and export a site before configuring uploads.

Before you begin

A few useful answers.

Which edition should I choose?

Use the 64-bit edition on 64-bit Windows. Choose the 32-bit edition for a 32-bit computer; that edition also runs on 64-bit Windows. Both contain the same editing features.

Do I need an account or an AI key?

Local editing, saving projects and exporting websites do not require a cloud account or an AI key. The optional Google Gemini assistant has its own account, project and key requirements. You can leave it unconfigured and continue using the editor.

What happens to my existing projects?

Your separately saved project files remain the editable source of your website. Keep a verified copy before an installation or upgrade, then open your project in the editor. Local draft storage is useful while working, but it is not a substitute for a separately saved project.

Why might Windows show a publisher prompt?

The application and installers are currently unsigned. Windows may display an unknown-publisher or reputation prompt. Check that you obtained the expected file and compare its SHA-256 fingerprint with the one supplied above.

Can I put the finished site on my own hosting?

The export contains HTML pages, supporting styles and scripts, and your assets. Compatible static web hosting can serve those files. Forms, online translation and other external services retain their own requirements; the guides explain the choices.

Where can I find the source and license?

The application is open source under the MIT license, with its OpenPage attribution preserved. The About page links to the source and provides the local license and third-party notices.
